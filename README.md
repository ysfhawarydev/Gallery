# Modern Responsive Website

A modern and fully responsive website built using HTML, CSS, and JavaScript. The project features a clean and attractive user interface with dynamic image functionality that changes images every time the page is refreshed.

## 🚀 Features

- Fully Responsive Design
- Modern and Clean UI
- Dynamic Image Generation on Refresh
- Semantic HTML Structure
- Smooth User Experience
- Organized and Maintainable Code

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## 📱 Responsive Design

The website is fully responsive and works seamlessly across:

- Desktop
- Tablet
- Mobile Devices

## 🎯 Purpose

This project was created to practice and improve frontend development skills, focusing on responsive design and DOM manipulation using JavaScript.

